# Игра "Эйдетическая Память" - Инструкция по установке и использованию

## 📱 О приложении

Это мобильное приложение на Flutter - игра для тренировки эйдетической памяти и визуально-пространственной обработки информации. Приложение портировано с оригинальной веб-версии (HTML/CSS/JavaScript) на Dart/Flutter.

**Эйдетическая память** - это способность запоминать информацию после короткого контакта без использования мнемонических приёмов.

## 🎮 Как играть

1. При запуске игры на экране отобразится слово на несколько секунд - **запомните его!**
2. Слово исчезнет, и появится игровое поле с 16 карточками
3. Нажимайте на карточки, чтобы их перевернуть и увидеть изображение
4. Найдите все 8 пар одинаковых изображений
5. После того, как все пары найдены, вам нужно будет вспомнить начальное слово
6. Выберите правильное слово из трёх вариантов
7. Получите результат и статистику!

## 🚀 Установка Flutter SDK

### Windows:

1. Скачайте Flutter SDK с официального сайта:
   ```
   https://docs.flutter.dev/get-started/install/windows
   ```

2. Распакуйте архив в папку (например, `C:\src\flutter`)

3. Добавьте Flutter в PATH:
   - Откройте "Переменные среды"
   - Добавьте путь к `flutter\bin` в PATH
   - Например: `C:\src\flutter\bin`

4. Проверьте установку:
   ```bash
   flutter doctor
   ```

### macOS:

1. Скачайте Flutter SDK:
   ```bash
   cd ~/development
   wget https://storage.googleapis.com/flutter_infra_release/releases/stable/macos/flutter_macos_arm64_stable.zip
   unzip flutter_macos_arm64_stable.zip
   ```

2. Добавьте в PATH (добавьте в ~/.zshrc или ~/.bash_profile):
   ```bash
   export PATH="$PATH:`pwd`/flutter/bin"
   ```

3. Проверьте установку:
   ```bash
   flutter doctor
   ```

### Linux:

1. Скачайте Flutter SDK:
   ```bash
   cd ~/development
   wget https://storage.googleapis.com/flutter_infra_release/releases/stable/linux/flutter_linux_stable.tar.xz
   tar xf flutter_linux_stable.tar.xz
   ```

2. Добавьте в PATH (добавьте в ~/.bashrc):
   ```bash
   export PATH="$PATH:$HOME/development/flutter/bin"
   ```

3. Проверьте установку:
   ```bash
   flutter doctor
   ```

## 🎨 Особенности реализации

### 1. Управление состоянием
Используется пакет `provider` для управления состоянием игры:
- `GameState` - класс, содержащий всю логику игры
- `ChangeNotifier` - уведомляет UI об изменениях

### 2. Анимации
- Плавные 3D-анимации переворачивания карточек
- Анимированные модальные диалоги
- Transition между экранами

### 3. Адаптивный дизайн
- Поддержка разных размеров экранов
- SafeArea для корректного отображения на устройствах с вырезами

### 4. Цветовая схема
Сохранена оригинальная цветовая палитра:
- Фон: `#FFE1C6` (светло-персиковый)
- Кнопки: `#09404C` (тёмно-синий)
- Текст кнопок: `#DCC7AA` (бежевый)
- Карточки: `#DDF4FF` (голубой) / `#FFE1C6` (персиковый)

## 📊 Логика игры

### Инициализация:
1. Создаются 8 базовых карточек с изображениями
2. Каждая карточка дублируется (итого 16 карточек)
3. Карточки перемешиваются случайным образом
4. Выбирается случайное слово для запоминания

### Игровой процесс:
1. Игрок нажимает на карточку → она переворачивается
2. Игрок нажимает на вторую карточку → она переворачивается
3. Если карточки совпадают → они остаются открытыми и исчезают
4. Если не совпадают → обе переворачиваются обратно
5. Счётчик попыток увеличивается
6. При совпадении увеличивается счёт

### Завершение:
1. Когда все 8 пар найдены → открывается диалог выбора слова
2. Если выбрано правильное слово → показывается поздравление с финальным счётом
3. Если выбрано неправильное слово → предлагается попробовать снова
4. В конце можно начать новую игру
